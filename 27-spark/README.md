# Витрина Boston Crimes на Apache Spark

Запуск через `spark-submit boston_mart.py crime.csv offense_codes.csv output_folder`. Все три пути передаются аргументами. Данные: [Kaggle AnalyzeBoston](https://www.kaggle.com/datasets/AnalyzeBoston/crimes-in-boston).

## Метрики и очистка

- Одна исходная строка преступления/правонарушения — единица подсчёта. Удаляются только полные дубликаты исходных строк; разные правонарушения одного инцидента сохраняются.
- Отбрасываются строки без района, ID инцидента, корректного кода или даты. Координаты 0, -1 и вне допустимых диапазонов заменяются NULL, но преступление остаётся в счётчиках.
- Справочник нормализуется до одного названия на CODE (детерминированно min(NAME)), поэтому JOIN не размножает факты. Тип — первая часть NAME до дефиса, с удалением внешних пробелов. Неизвестный код получает тип UNKNOWN и учитывается в отчёте качества.
- crimes_total — число очищенных строк района.
- crimes_monthly — точная медиана числа преступлений по наблюдавшимся месяцам `yyyy-MM`; январь разных лет разделён. Месяцы без строк не добавляются: источник не гарантирует полноту наблюдения для нулевого месяца. Для чётного числа месяцев берётся среднее двух центральных значений.
- frequent_crime_types — до трёх типов по убыванию частоты; при равенстве — по алфавиту. Разделитель `, `. `crime_type` — промежуточный атрибут, итоговая строка одна на район.
- lat/lng — отдельные средние по валидным значениям соответствующей координаты.
- coalesce(1) создаёт один part-файл Parquet в выходной папке (служебный _SUCCESS не является файлом данных). Существующая папка не перезаписывается.

## Docker

Из папки проекта в PowerShell:

```powershell
docker run --rm --user 0 -v "${PWD}:/work" apache/spark:3.5.7 /opt/spark/bin/spark-submit --master local[2] /work/boston_mart.py /work/data/crime.csv /work/data/offense_codes.csv /work/output
```

При отличающихся названиях скачанных CSV указать реальные имена. Для crime CSV по умолчанию используется ISO-8859-1; для UTF-8 передать `--crime-encoding UTF-8`. Справочник читается в UTF-8.

Интеграционная проверка:

```powershell
docker run --rm --user 0 -v "${PWD}:/work" apache/spark:3.5.7 /opt/spark/bin/spark-submit --master local[2] /work/test_mart.py
```

Тест проверяет удаление дублей, отсутствие размножения строк при дублях CODE, медиану по разным годам, порядок типов, исключение плохих координат из среднего, неизвестные коды и единственный Parquet-файл. Фактический протокол проверки добавляется после запуска.

[Документация Spark CSV](https://spark.apache.org/docs/3.5.7/sql-data-sources-csv.html).
